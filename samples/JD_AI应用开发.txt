岗位名称：AI 应用开发工程师（人工智能招聘专区 · 参考样例）

【岗位职责】
1. 参与公司 AI 应用产品的后端开发，负责接口设计与业务逻辑实现；
2. 基于大语言模型（LLM）能力进行应用落地，包括 Prompt 设计、RAG 知识库搭建与效果调优；
3. 配合算法团队完成模型能力的工程化封装与部署，保障服务稳定性；
4. 参与数据处理与清洗，协助构建高质量数据集。

【任职要求】
1. 本科及以上学历，计算机、软件工程、人工智能等相关专业，应届生可投；
2. 熟练掌握 Python，熟悉至少一种后端框架（Flask / FastAPI / Django）；
3. 熟悉 MySQL 或 PostgreSQL，具备数据库设计与 SQL 优化能力；
4. 了解大模型基本原理，有 Prompt 工程、LangChain、向量数据库（FAISS / Milvus）使用经验者优先；
5. 熟悉 Git 版本管理与 Linux 常用命令；
6. 具备良好的沟通能力与团队协作意识，有较强的学习能力。
