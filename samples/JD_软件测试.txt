岗位名称：软件测试工程师（2027 届校招）

【岗位职责】
1. 参与产品需求评审，编写测试用例，执行功能测试与回归测试；
2. 提交并跟踪缺陷，推动问题闭环；
3. 使用接口测试工具完成接口测试；
4. 参与自动化测试脚本的编写与维护。

【任职要求】
1. 本科及以上学历，计算机相关专业，2027 届毕业生；
2. 熟悉软件测试流程与常用测试方法；
3. 掌握测试用例设计方法，能独立编写测试用例；
4. 熟悉 SQL，能独立完成数据校验；
5. 了解 Postman 或 JMeter 等接口测试工具；
6. 了解 Python 或 Java 至少一种编程语言；
7. 工作细致，责任心强，具备良好的沟通能力。

【加分项】
- 了解 Selenium / Appium 自动化测试
- 了解缺陷管理工具（如禅道）
