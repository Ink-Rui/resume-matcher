# 操作手册（你自己看的）

> 这份手册解决一个问题：**你怎么把它跑起来、怎么在招聘会上当场演示。**

---

## 一、最简单的方式：双击运行

我在项目根目录放了一个 **`start.bat`**。**双击它**，会弹出命令行窗口，
3 秒后自动打开浏览器。用完了在窗口里按 `Ctrl + C` 就能关掉服务。

如果双击后窗口一闪就没，说明启动报错了——看下面的手动方式，那样能看到错误信息。

---

## 二、手动运行（推荐你至少走一遍，面试会问到）

打开命令行（Win + R 输入 `cmd` 回车），逐行执行：

```bat
cd /d C:\Users\Administrator\WorkBuddy\2026-10-15-16-10-07\resume-matcher
.venv\Scripts\python.exe app.py
```

看到这样的输出就成功了：

```
============================================================
  AI 岗位匹配分析器
============================================================
  大模型状态：未配置（将使用规则建议，功能不受影响）
  访问地址：http://127.0.0.1:5000
  停止服务：在本窗口按 Ctrl+C
============================================================
```

然后浏览器打开 **http://127.0.0.1:5000**

## 三、怎么用

1. **第 1 步 · 你的简历**：可以选「上传文件」（PDF / DOCX / TXT / MD），
   也可以选「粘贴文本」把简历内容贴进去
2. **第 2 步 · 岗位 JD**：把目标岗位的完整职位描述贴进去，**一定要包含「任职要求」那一段**，
   因为关键词主要在那里
3. **学历**：选「本科」，**工作年限**：填 0（你是应届）
4. 点「开始分析」

右边会出来：匹配度分数、技能命中情况、缺失的关键词（标红的是重点）、
门槛提示、改进建议。

## 五、配置大模型（让建议更聪明）

不配也能用，只是建议由规则模板生成。配置步骤如下：

1. 打开 https://open.bigmodel.cn ，用**手机号**注册（不用信用卡）
2. 登录后进「**API Keys**」页面 → 点「新建」→ 复制那串密钥（形如 `xxxxxxxx.yyyyyyyy`）
3. 用记事本打开项目里的 `config.json`，把密钥粘贴进去：

```json
"api_key": "把密钥粘贴在这里",
```

4. 保存，**重启服务**（关掉窗口重新双击 `start.bat`）

修改 `base_url` 和 `model` 就能换其他平台（通义、DeepSeek、腾讯混元都兼容这套格式）。

## 六、招聘会现场演示的话术（重要）

**别一上来就讲技术。** 先讲你为什么做它：

> "我在准备这次大会投递的时候发现一个问题：同一个岗位，不同公司 JD 写法差别很大，
> 我很难判断自己的简历和一个岗位到底差多少。所以我写了个小工具，
> 把简历和 JD 做关键词加权匹配，能告诉我缺哪些关键词、哪些是硬门槛。"

然后当场操作一遍（提前把简历和一段 JD 存在记事本里，别现场找文件）。

**如果 HR 问"这有什么用"**，你就说：

> "它帮我发现了一个问题——我原来简历里写的'机器学习基础'这种词，
> 在 JD 里其实对应的是具体的工具和框架名。关键词对不上，简历初筛就过不去。"

**最后一句**如果能说出来会很加分：

> "这个工具的核心匹配逻辑我没用大模型，是本地规则做的。
> 因为大模型给的分数不可复现、也没法解释，HR 问'为什么是 72 分'我答不出来。
> 所以我把确定性的事情交给规则，把表达交给大模型——大模型挂了工具照样能用。"

## 七、常见问题

**Q：双击 `启动.bat` 闪一下就没了？**
说明启动报错了。改用上面「手动运行」的方式，就能看到具体错误信息。

**Q：提示端口被占用（Port 5000 is in use）？**
说明已经有一个服务在跑了。先关掉之前的命令行窗口，或者重启电脑。

**Q：上传 PDF 提示"没有可提取的文字"？**
你那份 PDF 是扫描件（整页是图片）。改用「粘贴文本」，或者换成 DOCX。

**Q：想换端口？**
打开 `app.py`，把最后一行 `port=5000` 改成别的数字，比如 `port=8000`。

**Q：想把它发布到网上让别人也能打开？**
可以。把这个项目传到 GitHub，或者买一台云服务器（腾讯云有免费试用额度）
部署上去。部署方式：

```bash
# 在服务器上
pip install -r requirements.txt
python app.py     # 若要对外访问，需把 host 改成 0.0.0.0
```
